About

AI-kido is a community workshop for secondary school students in Malaysia, run in partnership with schools outside Universiti Malaya. It was built for the room it is used in: a projector, cheap phones, and a class that has heard “be careful online” too many times to listen again.

The session has two halves. First, the three patterns in Learn, taught through the messages themselves. Then the interactive game, where you apply the same checklist to a fictional scam.

Accessibility

This site is plain HTML, CSS and JavaScript, and stays readable with JavaScript switched off. Body text never drops below 17px, every control has a 44px target, focus is always visible, and motion is limited to colour changes.

If any part of this site is hard to use — on a small phone, with a screen reader, in a bright classroom — tell us and we will fix it.
